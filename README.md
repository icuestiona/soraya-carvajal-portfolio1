# Soraya Carvajal Portfolio

A minimalist portfolio for Soraya Carvajal, a communications strategist and front-end developer working across culture, technology, and digital communication.

## Structure

- `index.html` contains the semantic portfolio sections, navigation, selected projects, and contact details.
- `src/styles.css` defines the responsive editorial visual system, typography, project layouts, and motion states.
- `src/script.js` powers the full-screen menu, custom cursor, reveal animations, scroll accents, and ripple feedback.
- `src/images/` contains the portfolio photography and project imagery.

## Local preview

Open `index.html` directly in a browser, or serve the folder with any static HTTP server. The page has no build step or dependency installation requirement.

## Selected work

The work section highlights communication and web-development projects, including corporate communication, editorial work, education, banking, and image search experiences. Project cards link to their live published versions.
